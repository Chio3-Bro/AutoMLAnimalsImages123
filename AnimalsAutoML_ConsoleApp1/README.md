# Бот распознавания животных

Требуется .NET 8 и файл `AnimalsAutoML.mlnet` (копируется в каталог сборки).

## Запуск в PowerShell

```powershell
dotnet run --project AnimalsAutoML_ConsoleApp1.csproj
```

Остановка: Ctrl+C. Токен указан прямо в Program.cs; переменная окружения не требуется.


## Использование

- `/start`, `/help` — инструкция.
- Выберите несколько фотографий в Telegram и отправьте их альбомом либо по одной.
- Бот отвечает на каждую фотографию отдельно: три наиболее вероятных класса и оценки модели в процентах.
- Можно отправлять JPG/PNG как документы размером до 10 МБ.
- Ошибка на одной фотографии не останавливает обработку следующих.

Альбом приходит отдельными сообщениями с общим `media_group_id`; массив `photo` содержит разные разрешения одного снимка ([Telegram Bot API](https://core.telegram.org/bots/api#message)). Каждое сообщение обрабатывается последовательно, чтобы общий ML.NET PredictionEngine не использовался одновременно. Изображения загружаются в память без временных файлов.

Модель не переобучалась: она распознаёт только классы из существующего файла модели. Её оценки не являются гарантией правильного ответа.

## Проверка без Telegram

```powershell
dotnet build
dotnet run --project tests/BotChecks.csproj
```

Проверки используют поддельный HTTP-транспорт и классификатор; не отправляют сообщения в Telegram.
