# Порівняння облич — ASP.NET Core MVC

Вебзастосунок .NET 8 порівнює два портрети через Amazon Rekognition CompareFaces.

## Запуск

1. Вкажіть ключі AWS з дозволом `rekognition:CompareFaces` у локальному `AccessTokens.cs` (виключений із Git): властивості `AwsAccessKeyId` та `AwsSecretAccessKey` класу `AccessTokens` у просторі імен `AnimalsAutoML_ConsoleApp1`.
2. Виконайте `dotnet run --urls http://localhost:5080`.
3. Відкрийте http://localhost:5080 у браузері.
4. Для кожного фото виберіть файл **або** вставте пряме HTTP/HTTPS-посилання на JPEG/PNG. Можна використати дві URL-адреси, два файли або файл і URL.
5. Натисніть «Порівняти обличчя».

Посилання має вести на саме зображення, а не вебсторінку, і відкриватися без авторизації. Якщо заповнити файл та URL одночасно для одного фото, форма попросить залишити одне джерело. Після відповіді URL залишаються у формі, файли потрібно вибрати повторно.

Обмеження: до 5 МіБ та 20 мегапікселів на фото, JPEG/PNG. Завантаження URL обмежено 20 секундами та трьома перенаправленнями. Дозволені стандартні HTTP/HTTPS-порти; локальні й приватні адреси блокуються, зокрема після перенаправлення. Перевіряються формат, декодування, яскравість (від 45) та чіткість (від 5). Фото обробляються в пам’яті. Виклики AWS можуть тарифікуватися.

Регіон AWS задається у `appsettings.json`. Для публічного розміщення налаштуйте HTTPS. Ключі в C# компілюються в збірку, тому не поширюйте її з робочими секретами.

## Перевірки

```powershell
dotnet build
dotnet run --project tests/MvcChecks/MvcChecks.csproj
```

Перевірки використовують імітації завантажувача URL та AWS, без зовнішніх запитів.
